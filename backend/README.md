# ReclaimR Backend

## Overview

The backend of ReclaimR handles the server-side functionality
of the campus lost and found management system.

It will manage application logic, APIs, authentication,
data validation, and database communication.

## Technology Stack

- Node.js
- Express.js
- PostgreSQL
- REST APIs
- Postman
- Git & GitHub

## Main Responsibilities

- User registration and authentication
- Lost item management
- Found item management
- Item search and retrieval
- Claim management
- Admin operations
- Database communication
- Input validation
